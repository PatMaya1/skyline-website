# Demo Plan Presencia - Café Aroma

Esta es una página de demostración del **Plan Presencia** de SkyLine IT.

## Características Implementadas

✅ **Diseño Responsive**: Se adapta perfectamente a móviles, tablets y desktop
✅ **Hero Section Atractivo**: Con gradiente moderno y llamados a la acción
✅ **Botón WhatsApp Flotante**: Siempre visible con animación pulse
✅ **Navegación Fija**: Header que se mantiene al hacer scroll
✅ **Sección de Servicios**: Grid de 4 servicios con íconos
✅ **Galería Visual**: 6 elementos en grid responsive
✅ **Información de Contacto**: Horarios, dirección, teléfono
✅ **Redes Sociales**: Botones de Facebook, Instagram y WhatsApp
✅ **Animaciones Suaves**: Elementos que aparecen al hacer scroll
✅ **Menú Móvil**: Navegación hamburguesa para dispositivos móviles

## Tecnologías Utilizadas

- HTML5 semántico
- CSS3 con variables y Grid/Flexbox
- JavaScript vanilla (sin frameworks)
- Font Awesome para íconos
- Intersection Observer API para animaciones

## Negocio de Ejemplo

**Café Aroma** - Una cafetería artesanal moderna que representa perfectamente el tipo de negocio ideal para el Plan Presencia:
- Negocio local
- Necesita presencia en internet
- Busca atraer clientes cercanos
- Quiere mostrar sus servicios y ubicación
